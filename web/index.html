A shelf for everything else

Shake the pointer and a shelf appears for files, folders, links and text. Collect a few as you go, then move, ZIP, reveal or copy the whole lot in one pass — nothing is touched until you press the button.

Works in whatever you are using

Mail, Slack, a browser, Navicat, your editor. The bar is a panel, so clicking it never steals focus from the window you were in.

A click is not a selection

Clicking a table cell or a field that already had text selected does not summon the bar. Drag to select, or use the keyboard — those do.

Never reads passwords

Selections are ignored while secure input is active, and the clipboard is left exactly as it was. Copying a password yourself still works.

31 extensions, built in

DuckDuckGo, Wikipedia, GitHub, Maps, short links, title case, sort lines, Base64, word count, format JSON — plus any PopClip shell extension you import.

The last 100 things PopBar put on the clipboard, one click away. Identical copies collapse into one.

How it works

  1. A helper watches the selection. A small native program reads the focused element through the system's accessibility API and reports what is selected, and where.
  2. The app draws the bar. A non-activating panel appears below the selection, sized to your settings.
  3. An action runs. Click one and PopBar does the thing: puts text on the clipboard, opens a URL, or types the keystroke back into the app you came from.

Questions

macOS says the app is from an unidentified developer.

It is not notarized with an Apple Developer ID yet. Right-click the app → Open once, or run xattr -cr /Applications/PopBar.app. After that it launches normally.

Why does it need Accessibility permission?

That is the only way macOS lets a program read what another app has selected. PopBar asks for nothing else — no screen recording, no full disk access, no network access beyond update checks.

Can it read my passwords?

No. While secure input is active the helper reports nothing at all, and the clipboard fallback is skipped. Your own copy and paste in a password field are untouched.

Do extensions work on Windows?

Not yet — extensions are shell scripts, so they are hidden on Windows rather than offered and failing. The built-in actions all work there.

How do updates work?

PopBar checks the GitHub releases shortly after launch and replaces itself in place on both platforms: it downloads the new build, checks its SHA-512, swaps it in and reopens. macOS keeps the Accessibility permission you granted across updates; if it ever asks again after one, grant it once.

Where is my data?

In one folder on your machine (~/Library/Application Support/PopBar, or %APPDATA%\PopBar), readable only by you. Nothing is uploaded anywhere.
